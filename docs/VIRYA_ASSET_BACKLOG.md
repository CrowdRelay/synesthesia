# VIRYA × SYNESTHESIA — Asset Backlog

## Priorytet 0 — pipeline
- zachować obecny runtime budget,
- przygotowywać **mastery** w wyższej rozdzielczości, a do runtime eksportować jak dziś,
- każdą scenę projektować jako 4 warstwy: `background / scene / subject / foreground`.

## Priorytet 1 — hero upgrade
1. **Menu / intro**
   - alternatywny key art z mocniejszym motywem oka i obecnością postaci,
   - wersja oparta o świat Viryatkowa,
   - dalej zgodna z obecnym layoutem i DoorEyeMotif.
2. **Technophobia**
   - bardziej ludzka, sceniczna postać,
   - mocniejszy glitch, czytelniejsza twarz lub figura,
   - foreground z błędami, monitorami, pasami, przewodami.
3. **Unmasked**
   - centralna persona sceniczna,
   - maski w warstwach, lepszy silhouette read,
   - miejsce na przyszły kostium wokalny.
4. **Finale / Rise / Echoes**
   - najmocniejszy obraz całej gry,
   - jasne połączenie z VIRYA i wspólnotą zespołu,
   - finał ma czuć się jak kulminacja całego świata.

## Spec assetów
### Background
- spokojniejszy, z zapasem na parallax,
- mniej detali niż scene,
- master: min. 648×1152.

### Scene
- główny obraz pokoju,
- master: 1080×1920,
- w runtime eksport 675×1200.

### Subject
- najważniejsza postać / symbol / bohater,
- czytelna sylwetka na telefonie,
- master: 1080×1920.

### Foreground
- warstwa "wow": cząstki, maski, szkło, dym, przewody, balony, drzwi,
- master: min. 864×1536.
