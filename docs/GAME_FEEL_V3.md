# Synesthesia 2.1 — Game Feel / Resonance pass

## Non-negotiable loop
Every room follows: **find → manipulate → feel resistance → see/hear the world change → discover optional echoes → receive a unique completion beat**.

## What changed
- Continuous room-specific WorldMicroFX for all 11 visual styles.
- Semantic audio clearance: meaningful interactions reduce noise and reveal music independently of brush coverage.
- Rich Echo Codex metadata: source, role, echo type and memory text survive save/restore.
- Finale is now an interaction: Yanusin, Mr R, Lubek and Koobosky must be joined into one resonance before the final action panel opens.
- Technophobia cable pulls now emit progressive tension haptics before unplugging.
- Existing behavior state remains persistent, so removed masks, broken mirrors, grown roots and solved room state survive the journey.

## Quality rule
No room should be completed by arbitrary scribbling. Painting is an accessibility/reveal layer; room mechanics own progression and payoff.
